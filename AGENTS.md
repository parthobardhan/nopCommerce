# nopCommerce (Cursor demo)

ASP.NET Core storefront. Prefer plugins over core. Widget zones over controller HTML.

- Conventions: `.cursor/rules/nopcommerce-conventions.mdc`
- New storefront widgets: skill `add-widget-plugin`
- Do not edit `CheckoutController` or `Nop.Services/Orders` for banners
- Do not commit `App_Data/appsettings.json`
